# Portfolio

Personal site of Ayoub Said. Plain HTML and CSS with no build step.

## Run locally

There's nothing to install. Open `index.html` in a browser, or serve the folder with any static file server.

## Files

- `index.html`: all of the page content
- `styles.css`: layout and colours, light and dark
- `script.js`: keeps the age current and copies the Discord handle
- `favicon.svg`: tab icon
